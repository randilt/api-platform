## How to read this

- **proven flaky:** the same commit both passed and failed (a rerun, or another leg of one run), so the failure can't be the code.
- **broken for a period:** three or more runs in a row failed, on two or more branches: something on main was broken for everyone.
- **fails on one branch only:** every failure was on one branch, so that branch's change is the first suspect.
- **likely flaky:** failed on several branches with passes in between.
- **one-off:** failed once in the window.
- **Incidents** are failures where 5 or more scenarios of one block failed in the same job. They point at one cause, so they don't count towards any scenario's verdict or failure rate.
- Categories come from rules on the failure text; `other` means no rule matched yet. The full per-run data is in `executions.jsonl`, and `allure-report` shows every run of a scenario on its page.
- Only the Platform Tests jobs are read: they run the suites with `-v`, which prints every scenario's result. Scenarios tagged `@known-issue` are excluded from runs, so they never appear.
